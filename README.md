# استوديو محاكاة الهندسة الصوتية للتلاوات القرآنية
### Quranic Audio Style & Reverb Cloner (DSP Engine & Studio Web App)

تطبيق ويب محلي متكامل واحترافي مصمم خصيصًا لهندسة التلاوات القرآنية. يهدف التطبيق إلى استخلاص البصمة الصوتية والمكانية (EQ والصدى المسجدي Reverb) من أي تلاوة قرآنية مرجعية، وتطبيقها بنقاء تام وبدون أي تشوه معدني على تلاوة المستخدم الخام.

---

## 🌟 المعمارية الهندسية لمعالجة الإشارات (DSP Pipeline)

تم بناء المعالجة الصوتية بشكل معياري داخل `backend/dsp/` عبر خمس مراحل متتالية:

1. **التجهيز المسبق وتنقية التسجيل الخام (`preprocessor.py`):**
   - توحيد معدل العينات إلى `44.1kHz` بصيغة `32-bit float` استيريو.
   - تطبيع القمم الصوتية (Peak Normalization) إلى `-3.0 dBFS`.
   - تنقية تلاوة المستخدم الجافة عبر فلتر تمرير عالي (Highpass عند `80Hz`) وبوابة ضجيج ذكية (NoiseGate) لتنظيف صوت التنفس والهمهمة قبل تطبيق المؤثرات.

2. **الفصل العصبي للصدى عن الصوت الجاف (`separator.py`):**
   - فصل التلاوة المرجعية إلى صوت جاف خالص (`ref_dry.wav`) وفضاء الصدى وحده (`ref_reverb.wav`).
   - دعم نماذج `UVR-DeEcho-DeReverb` مع تسريع تلقائي على بطاقات كرت الشاشة (CUDA) والتحول التلقائي للمعالج (CPU).
   - توفير محرك De-Reverberation طيفي عالي الدقة مبني على تفكيك التماسك والنبضات العابرة (Transient-Coherence Decomposition).
   - نظام تخزين مؤقت ذكي مبني على بصمة الملف (`MD5 Hash`) لتفادي إعادة الفصل عند تجربة إعدادات مختلفة على نفس التلاوة.

3. **مطابقة اللون الترددي والديناميكية بين الجاف والجاف (`tone_matcher.py`):**
   - **قاعدة ذهبية:** مطابقة الترددات تتم بين تلاوة المستخدم وصوت القارئ المرجعي الجاف حصراً لمنع تشويه الصوت بذيل الصدى.
   - محرك المطابقة الطيفية الناعمة (Smooth Spectral EQ): حساب كثافة الطاقة الطيفية (Welch PSD) للمقاطع النشطة فقط، والتنعيم على نطاقات ثلث أوكتاف مع حصر الكسب بين `-12dB` و`+12dB`، وتطبيقه بفلتر خطي الطور (Linear-Phase FIR) وضغط صوتي ناعم (Compressor).
   - دعم التبديل لمحرك `Matchering`.
   - منزلق تحكم بنسبة المطابقة الترددية (`eq_intensity`).

4. **استخلاص وتوليد البصمة المكانية للصدى (`reverb_cloner.py`):**
   - **الوضع الافتراضي (التوليد البارامتري النقي Parametric IR Synthesis):** قياس نسبة الرطب/الجاف، وزمن التأخير المسبق (Pre-delay)، وزمن التلاشي (RT60) بتكامل شرودر العكسي عبر نطاقات متعددة (من `125Hz` إلى `8kHz`)، ثم توليد استجابة نبضية استيريو فائقة النقاء (`extracted_ir.wav`) بضجيج مخملي مشكل طيفيًا بدون أي رنين معدني.
   - **الوضع الثاني (فك الالتفاف الطيفي Wiener Deconvolution):** الحساب الرياضي لفك الالتفاف في النطاق الترددي مع نافذة تلاشٍ أسي.

5. **الدمج المكاني، الخفض التلقائي، والماسترينغ (`mixer.py`):**
   - الالتفاف السريع (FFT Convolution) للبصمة المكانية.
   - **الخفض التلقائي للصدى أثناء النطق (Sidechain Reverb Ducking):** خفض الصدى بمقدار `2.5 dB` أثناء نطق الآيات لتبقى مخارج الحروف جلية، ثم بروزه طبيعيًا عند الوقف.
   - محدد صوتي حقيقي (Mastering Limiter عند `-1.0 dBFS`) وتصدير التلاوة بجودة استوديو `WAV 24-bit`.

## 🚀 واجهة الويب العربية وتجربة المستخدم (SPA)

- **الهوية البصرية:** تصميم داكن عصري مستوحى من استوديوهات الصوت مع ألوان القرآن الهادئة (الرمادي الكحلي `#0f172a`، الأخضر الزمردي `#10b981`، والذهبي الهادئ `#d4af37`) بخط `Cairo` و`Tajawal`.
- **مشغلات تفاعلية:** مشغلات أمواج صوتية تفاعلية بمكتبة `WaveSurfer.js`.
- **تسجيل ميكروفون مباشر:** إمكانية التسجيل الحي من المتصفح مع مؤشر فوري لمستوى الصوت (Audio Level Meter).
- **مقارنة لحظية (A/B Switch):** تبديل فوري أثناء الاستماع بين (تلاوتك الخام / تلاوتك بالهندسة / التلاوة المرجعية) في نفس الثانية دون انقطاع.
- **رسم بياني للطيف الترددي (`Chart.js`):** مقارنة بصرية لثلاثة خطوط استجابة ترددية.
- **تصدير واحتفاظ بالبصمة:** تحميل التلاوة النهائية `WAV 24-bit` وتحميل ملف الاستجابة النبضية `IR.wav` لاستخدامه في برامج المونتاج مثل Audition وReaper.

## 🛠️ التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل خادم الويب:
```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
ثم افتح المتصفح على الرابط: `http://127.0.0.1:8000`

## 💻 استخدام سطر الأوامر (CLI)

يمكنك معالجة التلاوات دفعة واحدة أو بدون واجهة رسومية عبر الملف `cli.py`:

```bash
python cli.py --ref "path/to/reference.wav" --target "path/to/target_dry.wav" --out "quranic_master.wav" --ir-out "extracted_ir.wav" --eq-intensity 0.8
```

### الخيارات الإضافية:
- `--decay-scale 1.2`: تكبير زمن صدى المسجد بنسبة 20%.
- `--reverb-mix 0.40`: تحديد نسبة دمج الصدى يدوياً (0.0 إلى 1.0).
- `--reverb-mode wiener`: استخدام خوارزمية فك الالتفاف الطيفي.
- `--no-ducking`: تعطيل ميزة خفض الصدى التلقائي أثناء النطق.
- `--no-clean`: تعطيل الفلتر الأولي لتنقية صوت المستخدم.
